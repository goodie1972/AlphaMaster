# US_Range_Fade_EA — 美盘 H4 区间 M5 假突破回归

震荡策略：以美盘第一根 H4 定区间，M5 假突破回归挂单，RR=2，每日每轨一次。
逻辑与 `mt5/backtest_us_range_fade.py` 逐条镜像，23 项单元测试锁定规则。

> **结论先行：ADX<25 不是盈利开关，只减亏不扭亏。本策略毛利边缘极薄，成本是真正的杀手。详见下方回测。**

## 规则

1. **参照棒**：每日服务器 16:00–20:00 的 H4（含纽约 9:30 开盘，券商 UTC+2/+3 冬夏令时均对齐）。
   合格 = 实体 ≥ `BodyRatio`×(H−L) 且 |实体中点−区间中点| ≤ `CenterTol`×(H−L)。不合格当日不交易。
   （默认 0.5/0.25 下居中判据数学上冗余——实体≥半区间必然居中≤1/4 区间；调小 BodyRatio 才独立生效。）
2. **轨道**：上轨=H、下轨=L。M5 监控窗 = 服务器 20:00–24:00。
3. **空**：M5 收盘 > 上轨 → 标记，跟踪标记以来最高价（含标记棒）；后续收盘 ≤ 上轨 → 该收盘价做空。
   SL=标记后最高价，TP=入场 − RR×(SL−入场)。**多**：镜像（收盘 < 下轨标记跟踪最低价，收盘 ≥ 下轨做多）。
4. **约束**：每轨每日仅首次突破标记一次；开仓后该轨当日作废；ADX 挡掉的回归同样作废该轨（保守一次性）；
   不回归不开仓；最多 1 笔持仓；持仓期间跳过信号；双触 SL/TP 同根 bar 回测按**先止损**（保守）；
   24:00（窗口最后一根 M5 收盘）强平未触 SL/TP 的持仓。
5. **ADX 门**：入场棒 M5 Wilder ADX(14)，`ADX ≥ AdxMax` 挡单；`UseAdx=false` 关闭。

## 输入参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `InpRiskPercent` | 1.0 | 每笔风险%（按权益反算手数） |
| `InpBodyRatio` | 0.5 | 参照棒实体/区间 下限 |
| `InpCenterTol` | 0.25 | 实体中点偏离上限（×区间） |
| `InpRR` | 2.0 | 止盈 = RR × 止损距离 |
| `InpUseAdx` | true | ADX 过滤开关 |
| `InpAdxPeriod` | 14 | ADX 周期（M5） |
| `InpAdxMax` | 25.0 | ADX ≥ 此值挡单 |
| `InpRefHour` | 16 | 参照 H4 开盘小时（服务器钟） |
| `InpMagic` | 20261120 | 魔术号 |
| `InpDeviation` | 20 | 市价单滑点（points） |

手数 = 权益×RiskPercent/100 ÷ (SL距离/tick_size×tick_value)，向下取整到 volume_step；
低于最小手数则跳过该信号（不强行开仓）。XAUUSD 1 手=100 oz。

**数据**：M5 99999 根，服务器钟 **2025-06-25 → 2026-11-20**（约 17 个月）。
请求近 2 年，但券商 M5 历史深度只到 2025-06-25（更早分块返回空），H4 深度充足（2024-04 起）。
16:00 参照棒 364 根落在 M5 区间内，其中 163 根合格。成交价=回归棒收盘价（与台账同口径）。

## ADX<25 要不要 —— 裁定

**不需要把它当盈利开关；它只减亏不扭亏，且机制上反而恶化成本比。**

1. **毛利边缘极薄**：零成本下最好的「关」也只有 +3.97%/17 个月、PF 1.13，胜率 41%×RR2 恰在盈亏线附近。
   ADX 过滤把 PF 略抬（关 1.13 → <30 1.26）但总收益更低——它砍掉的是大止损的趋势日交易，留下的边缘没变厚。
2. **成本是真正的杀手**：台账口径往返 2.13 美元，而平均止损距离仅 4–12 美元，成本占风险 18–51%。
   任何口径下净收益都为负；近真实成本（0.0001）下「关」−9.52%、<25 −5.12%。
3. **ADX 过滤反而恶化成本比**：ADX<25 选中的是低波动日，H4 区间更窄 → 平均止损从 11.69 缩到 4.16 美元，
   成本占风险比从 18% 飙到 51%。所以 <25 胜率从毛利 33% 掉到含成本 26.7%，比「关」掉得更狠。
   它靠砍掉 75% 交易（61→15）把绝对亏损减半，但每笔质量更差。
4. **样本小**：17 个月仅 61 笔（关）/15 笔（<25），2025 与 2026 表现分化，统计上不足以支撑实盘。

**建议**：若仍要跑，`UseAdx=true, AdxMax=25` 作为减亏风控（默认值），但**不建议实盘**——
毛利边缘撑不起真实点差+佣金。要救活得从「降低成本占风险比」入手（更宽区间/更大 RR/更高周期），而非调 ADX 阈值。

## 回测与实盘口径差异（须知）

- 回测成交价=回归棒**收盘价**；EA 在回归棒收盘瞬间**市价**进场，有点差/滑点。
- 双触 SL/TP：回测保守按先止损；实盘由 broker tick 顺序决定。
- 24:00 强平：回测用 23:55 收盘价；EA 在下一根 tick 市价平仓。
- 重启接管以真实持仓为准，回放出的入场若已不在则不追溯补单。
