# ST+QQE 配方 EA 说明（mt5/ST_QQE_Recipe_EA.mq5）

可真实下单的 Expert Advisor，实现回测验证过的 ST+QQE 冠军配方。仅适用于 **XAUUSD M30**（其他品种自动禁用）。与 AlphaMaster EA 的 magic 不同，可共存互不干扰。

## 快速开始

1. MetaEditor 打开 `ST_QQE_Recipe_EA.mq5`，编译（F7）
2. 挂到 **XAUUSD 的 M30 图表**，允许自动交易
3. 默认参数即冠军配方，无需修改；建议先 `InpTradeEnabled=false` 或模拟盘观察几天信号节奏
4. 图表左上角面板实时显示：event（本根信号）、target（目标仓位）、er（状态门数值）、状态

## 策略规则（一句话版）

**慢 QQE 出信号 → ST 趋势同向 + 市场处于单边状态 → 入场/反手；反向 QQE 信号 → 平仓（过门则直接反手）。**

逐条定义（全部在 bar 收盘时决策，下一根执行，无前视）：

| 部件 | 规则 |
|---|---|
| 触发器 | 慢 QQE MOD（RSI长度20、平滑12，主/副两条）的 up/dn 信号**出现当根**（当根有效、前根无效） |
| 方向确认 | SuperTrend AI（默认参数）当前趋势方向必须与信号同向 |
| 状态门 | 效率比 ER96 = \|今收−96根前收\| ÷ 最近96根路径总长 ≥ 0.35（震荡市拒绝信号） |
| 入场 | 空仓时信号过两道门 → 开仓 |
| 反手 | 持仓中反向信号过门 → 平旧开新 |
| 出场 | 反向信号**未过门** → 只平仓不反手 |
| 无信号 | 维持现状 |
| 止损后 | 灾难止损/手工平仓后**空仓等新信号**，不盲目重开旧仓 |

不做部分减仓、不加去抖——回测证明减半/加回机制增加换手、砍掉趋势段利润，全部跑输本配方。

### 慢 QQE 触发器（冠军参数）
主/副 RSI Length = 20、Smoothing = 12；主因子 3.0、副因子 1.61、阈值 3.0、布林 50/0.35。**不建议微调**（邻域峰值已验证，再调是过拟合风险）。

### SuperTrend AI 确认（默认）
ATR 10、因子范围 1–5 步进 0.5、性能记忆 10、Best 簇、迭代 1000。EA 对加载的全部历史算 k-means（无指标版 maxData 屏幕限制）。

### 状态门 / 数据
| 输入 | 默认 | 说明 |
|---|---|---|
| ER Len | 96 | 效率比窗口（≈2天） |
| ER Threshold | 0.35 | 单边市判定阈值 |
| History Bars | 5000 | 参与计算的已收盘 bar 数 |
| Min Bars | 400 | 低于此根数不交易（warm-up） |

## 手数与止损

- **固定手数**（默认）：每次 0.01 手
- **风险手数**（Risk Sizing=true）：手数 = 净值×Risk% ÷ (止损距离×每手每点价值)，自动对齐品种最小/步进/最大手数。例：$5k 净值、1% 风险、止损距离 20×ATR ⇒ 每笔最多亏 $50
- **灾难止损**：开仓后按实际成交价挂 broker 侧 SL = entry ∓ 20×ATR(14)，每根 bar 自动修复（手工挪走/重启丢失会挂回）。20×ATR 极难触发，是安全垫不是出场逻辑
- 止损禁用（=0）时风险手数自动退回固定手数

## 注意事项

1. **回测不含止损**：灾难 SL 是安全overlay，实盘与回测会有微小偏差；正常出场全靠反向信号
2. **回撤预期**：OOS 最大回撤 26.4%，训练期 44.5%；2016–2018 型长期震荡市会连续小亏，这是策略的正常呼吸，不是故障
3. **成本敏感**：回测按 0.02%/边；你的实际点差越低越好（0.01%/边时 OOS +19.7%）
4. **信号核对**：挂 QQE_MOD 指标（参数改 20/12）+ 默认 SuperTrend_AI 指标，EA 开仓时应能看到慢 QQE 信号柱 + ST 同色趋势线
5. **每根 M30 收盘算一次**（含 k-means），tick 之间不动作；挂载/重启时按最近收盘 bar 立即调仓一次
6. 先模拟盘验证，再实盘；实盘建议 Risk Sizing=true 起步
